# NV-1 Evaluation

Parity must be measured rather than estimated.

## Core dimensions
- General knowledge
- Mathematical reasoning
- Scientific reasoning
- Coding and debugging
- Instruction following
- Long-context retrieval/reasoning
- Tool use
- Multilingual ability
- Factuality
- Robustness and safety

Every benchmark should use a fixed version, documented prompt protocol, held-out data, and repeated runs where appropriate. Report raw scores and confidence intervals rather than a single “intelligence percentage”.

The existing NV-0.2 test set is not sufficient for a frontier comparison; its five held-out examples are useful only as a regression smoke test.
