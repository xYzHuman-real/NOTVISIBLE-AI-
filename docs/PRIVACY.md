# NOTVISIBLEAI Privacy Notice — Draft

This repository contains a technical draft, not legal advice.

A production deployment should clearly document what information is collected, why it is processed, retention periods, subprocessors, security controls, user rights and contact information. The API should not log message content by default. If request/response logging is enabled for debugging, configure an explicit retention policy and access controls.

Before public launch, have the final privacy notice reviewed for the jurisdictions and users you actually serve.
